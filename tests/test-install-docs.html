Installing Example CLI

Open a terminal and paste the command for your platform, then press Enter.

macOS and Linux

curl -fsSL https://cli.example/install.sh | bash

Windows

powershell -ExecutionPolicy ByPass -c "irm https://cli.example/install.ps1 | iex"

Verify the installation

Run example --version to check the CLI is on your PATH. If your shell can't find it, open a new terminal window so it picks up the updated PATH, or press Ctrl + V to paste the full path printed by the installer.
